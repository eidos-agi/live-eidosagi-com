**The claim**: by month two, this site is writing its own activity feed — via a local llama 3 running on the A6000 that also produces the numbers you see — not via Claude.

**Why this is the vision**:
- The whole site argues "local models are cheap, ready, and yours."
- Nothing proves that argument harder than **the site itself abandoning hosted LLMs mid-run** and continuing on its own silicon.
- A live tracker — "% of events generated by local models this week" — climbs from 0% toward 100%. Visitors *watch* the cost drop.

**Milestones**:
1. The eidos-live MCP is wired. Every meaningful action from Claude streams to /api/ingest. ← shipping today.
2. An Ollama-backed event-summarizer daemon runs on the A6000. Ingests raw tool-call records, emits headline-style event summaries, posts them via /api/ingest with actor='benchmark' (or a new actor='local-llm').
3. A dashboard widget: **"X% of recent events written by local AI, saving $Y this session"** — updates live. Computed from cost-per-event at the current Claude rate vs ~$0 (already-paid A6000 hourly).
4. Gradual transition: local model handles progressively more event types (commit narration first, then subagent summaries, then decision framings, finally all). Each transition emits a milestone event: "event narration shifted to local llama3.1:8b at 16:42Z — saved $X since launch."
5. When the A6000 is generating its own benchmark narrations, the loop closes. The page is literally self-sustaining.

**Why it's achievable**: A6000 at $0.35/hr renders llama3.1:8b at 80 tok/s. Headline-length summaries are ~30 tokens. One summary costs ~$0.0001 in GPU time (and is already paid). Claude-generated summaries via API are ~$0.001-0.01 each. Savings are 10-100× per event and visible.

**Dependencies**: Phase 2 (eidos-live MCP live) → Phase 3 (full GPU battery visible) → Phase 4.
